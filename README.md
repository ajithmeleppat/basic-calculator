# basic-calculator
Calculator Project from The Odin Project Foundations Course
[Live Demo](https://ajithmeleppat.github.io/basic-calculator/)


This is a basic calculator implementation which evaluates a single pair of numbers at a time. The following operations are supported:
* add
* subtract
* multiply
* divide

The following expresssion: ${1 + 2 * 5}$ will evalate to 15 and not 11.
